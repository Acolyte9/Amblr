# Amblr
Brainstorming for writing while walking

Team Contract:

1. If you have a responsibility and nobody else is aware of it, then it is entirely your responsibility. 

2. Respect the dates. If you cannot work with a certain date, let everyone know ahead of time - preferably as soon as you become aware.

3. Remember to Pull from Github before pushing to Github. Try to communicate with the team before creating files or organizing files into folders. Try to cohere with the structure the team has set.

4. Try to add comments explaining what purpose each part of the code serves. Ideally, each file should have at least one comment explaining what the file does and how it should connect to other files; feel free to add further elaboration on smaller sections of code inside the file.
